Проект: Оптимизация сверки данных между 1С и WMS

Задача:
Сверка остатков/движений товаров между последовательностями 1С и WMS. Ручная сверка заняла около 30 минут на смену.

Решение:
Разработан скрипт на Python (библиотеки pandas, re) для сравнения выгрузок (файлы .xls) из данной системы.

Результат:
Время обработки сокращается с 30 минут до 5 минут за смену.

Скрипт используется ежедневно (355 дней в году без учета выбросов).

Расчет экономии рабочего времени:
Ручная обработка: 355 дней × 30 минут / 60 = 177,5 человеко-часов в год

Автоматизированная обработка: 355 дней × 5 минут / 60 = 29,6 человеко-часов в год

Экономия: 147,9 человеко-часов в год
